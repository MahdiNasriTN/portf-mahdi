# portf-mahdi

Portfolio of Mahdi Nasri, Software Engineer. A scroll-driven Next.js site (GSAP, ScrollTrigger, Lenis).

```bash
npm install
npm run dev     # http://localhost:3000  (redirects to /nesilnoble)
npm run build
```

- Page: `src/app/nesilnoble/`, markup in `src/components/sites/nesilnoble/markup.ts`
- The markup, styles and scroll script are generated by `node scripts/nesilnoble/build.mjs` from `docs/research/nesilnoble/source-original.html`; Mahdi's own copy and projects live in `scripts/nesilnoble/build.mjs` and `scripts/nesilnoble/profile.mjs`.
- Assets: `public/sites/nesilnoble/`
