# portf-mahdi

Portfolio of Mahdi Nasri, Software Engineer. A scroll-driven Next.js site (GSAP, ScrollTrigger, Lenis).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- Page: `src/app/page.tsx`, markup in `src/components/home/markup.ts`
- The markup, styles and scroll script are generated by `node scripts/home/build.mjs` from `docs/research/home/source-original.html`; Mahdi's own copy and projects live in `scripts/home/build.mjs` and `scripts/home/profile.mjs`.
- Assets: `public/home/`
